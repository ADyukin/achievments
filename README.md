# Мастер оценок — iOS-прототип

Нативный SwiftUI-прототип виджета достижений из Figma. Шрифт Onest, оригинальные ресурсы и переход между уровнями.

## Посмотреть без Xcode

Скачайте [автономное браузерное превью](outputs/AnimationPreview/index.html) и откройте HTML обычным браузером. Установка, сервер и интернет не нужны: Onest и исходные PNG встроены в файл. По умолчанию проигрывается **02 · Перелив**. Доступны исходная анимация, два новых направления, повтор, пауза и скорость 0,5×. [GIF «Перелив»](outputs/AnimationPreview/transfer.gif) показывает браузерную версию движения.

Это превью движения, а не точный рендер iOS: системные элементы, исходные пружины и `numericText` браузер воспроизводит приближённо. Остальные товары после достижения показаны только для чтения; оценка первого товара интерактивна.

## Анимации

- **01 · Исходная** — прежняя последовательность сохранена без изменений.
- **02 · Перелив** — заполненная полоса становится одной непрерывной лентой и втягивается в значок. После прихода ленты значок вместе с номером увеличивается, цифра меняется, затем всё плавно возвращается.
- **03 · Световой проход** — один световой проход по полной полосе в сторону значка и такое же завершение уровня.

В новых вариантах нет кольца, россыпи частиц, наклона, деформации или независимых подпрыгиваний. Размеры карточки, тексты, исходные изображения и модель оценок не менялись. Координаты переноса вычисляются из фактической раскладки.

## Запуск iOS

Откройте `outputs/AchievementDemo/AchievementDemo.xcodeproj` в Xcode, выберите iPhone Simulator и нажмите Run. Требуется iOS 17 или новее. Сторонних библиотек нет.

В меню **Анимация** выберите вариант и **Повторить 2 → 3**. Выбор запоминается. Для ручного запуска выберите в меню «Демо» пункт «До уровня 3 — 1 оценка» и оцените товар. Аргумент `--demo-count 39` открывает то же состояние.

Оценки хранятся в памяти. Каждые 20 новых оценок повышают уровень; повторная оценка одного товара не добавляет прогресс. Reduce Motion отключает пространственные эффекты. Уход в фон и смена варианта отменяют переход и показывают актуальное состояние.

Начальный, промежуточные и финальный кадры просмотрены. Проверено сохранение исходной последовательности и содержания.
