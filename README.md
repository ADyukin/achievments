# Мастер оценок — iOS-прототип

Нативный SwiftUI-прототип виджета достижений из Figma. Шрифт Onest, оригинальные ресурсы и анимация перехода между уровнями.

## Запуск

Откройте `outputs/AchievementDemo/AchievementDemo.xcodeproj` в Xcode, выберите iPhone Simulator и нажмите Run. Требуется iOS 17 или новее. Сторонних библиотек нет.

Для перехода 2 → 3 выберите в меню «Демо» пункт «До уровня 3 — 1 оценка» и оцените товар. Аргумент запуска `--demo-count 39` открывает то же состояние.

## Текущее поведение

Шкала заполняется, по белой карточке проходит шиммер. Значок уходит вниз, плашка номера увеличивается до 220% и перемещается в центр левой области. Цифра меняется с 2 на 3, затем элементы возвращаются на свои места. Конфетти временно выключено; реализация сохранена.

Оценки хранятся в памяти. Каждые 20 новых оценок повышают уровень; повторная оценка одного товара не добавляет прогресс. Поддерживается Reduce Motion.
