# Автономное превью анимации

Скачайте `index.html` и откройте обычным браузером. В файл встроены исходные PNG значка и парфюма и Onest.ttf. Зависимости, сервер и интернет при просмотре не нужны. Управление вне макета: исходная анимация, «Перелив», «Световой проход», повтор 2 → 3, пауза, сброс, скорость 1×/0,5× и Reduce Motion. «Перелив» выбран по умолчанию и проигрывается один раз.

Новый основной вариант — непрерывная лента из самой заливки полосы и один акцент всего значка. Второй — проход блика к значку. Кольцо, россыпь частиц и независимые подпрыгивания удалены. Исходная последовательность сохранена для сравнения.

Это браузерное превью, не нативная сборка: SwiftUI easing и numericText приближены общим RAF-таймлайном; системные элементы и пиктограммы воспроизведены в HTML/SVG. Исходные тексты, изображения и палитра сохранены. Можно оценить первый товар или изменить его звёзды, остальные строки после достижения доступны для чтения. Полная логика оценок остаётся в SwiftUI-приложении.

При уходе со вкладки или смене варианта переход отменяется и показывает актуальный итог. Системное уменьшение движения и флажок отключают пространственное движение.

## Проверка и экспорт

Из корня репозитория:

```sh
python outputs/AnimationPreview/build.py
node outputs/AnimationPreview/verify.cjs
node outputs/AnimationPreview/render-gif.cjs
ffmpeg -y -framerate 25 -i /tmp/achievement-preview-harmony/%03d.png -filter_complex '[0:v]split[a][b];[a]palettegen=stats_mode=diff[p];[b][p]paletteuse=dither=sierra2_4a' -loop 0 outputs/AnimationPreview/transfer.gif
```

Сборщик использует стандартную библиотеку Python. Проверки/экспорт требуют Playwright и Chromium (`CHROMIUM_PATH` можно переопределить), сборка GIF — ffmpeg. Тест читает локальный HTML через `setContent`, без сервера. GIF — экспорт браузерного рендера при 25 fps, не запись симулятора.

Проверено: три варианта, точка смены цифры, пауза/повтор/скорость/смена варианта, отмена при скрытой вкладке, финальные уровень 3 и пустая полоса, системный и ручной Reduce Motion, мобильная ширина без горизонтального переполнения, отсутствие сетевых запросов и JS-ошибок. Кадры `start.png`, `full.png`, `transfer.png`, `arrival.png`, `accent.png`, `final.png`, `mobile.png` получены тем же рендерером и просмотрены. Во время перехода показывается один товар, после завершения — следующая группа; тестовый seek сбрасывает это состояние независимо от истории запусков.

Нативный код прошёл syntax parse и проверки модели. Исходная анимационная последовательность и содержание сравнены с предыдущей версией без изменений. Xcode и нативного рендера здесь нет.
